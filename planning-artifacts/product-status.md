# Bisli - סטטוס פיתוח ותהליכים

> עדכון אחרון: 13.5.2026

## סיכום מערכת

מערכת ניהול הדרכה וקורסים לארגון חינוכי.
React + Fastify + PostgreSQL + S3 (MinIO).

## מסכים קיימים

1. **כניסה** - בחירת משתמש (סביבת פיתוח)
2. **האזור שלי** - טיימליין אישי עם קורסים מאושרים, סטטוס בקשות ומועמדויות
3. **קורסים ולו"ז** - קטלוג ממוין לפי חודש, לחיצה פותחת מודאל עם פרטים + הרשמה
4. **מועמדות לפיקוד** - כרטיסים לכל מועמדות, הגשה חדשה במודאל עם קבצים
5. **אישור רישום** - כרטיסים ממתינים לאישור, אשר/דחה במודאל
6. **ניהול** - טאבים: משתמשים, קורסים ומחזורים, ענפים וצוותות, יומן פעולות

## תשתית טכנית

- **Repo:** github.com/airbnbmate/coursit
- **Backend:** Fastify + Prisma + TypeScript
- **Frontend:** React + Vite + Tailwind CSS
- **DB:** PostgreSQL (Docker)
- **אחסון קבצים:** MinIO (S3-compatible) עם TTL 3 חודשים
- **Docker Compose:** DB + MinIO + DB Viewer

---

## הרצה מקומית

```bash
git clone git@github.com:airbnbmate/coursit.git
cd cursit
docker compose up -d
npm install
cd backend && npx prisma db push && npx tsx src/scripts/seed/dev.ts
cd .. && npm run dev
```

**כתובות:**
- Frontend: http://localhost:3005
- Backend: http://localhost:8000
- MinIO Console: http://localhost:9001 (cursit / cursit123)
