# Bisli - מסמך מוצר מפורט

> עדכון אחרון: 13.5.2026
> גרסה: 1.0-alpha

---

## 1. סקירה כללית

**שם המוצר:** Bisli
**תיאור:** מערכת ניהול הדרכה וקורסים לארגון חינוכי. מאפשרת רישום לקורסים, מועמדות לתפקידי הובלה, ניהול שרשרת אישורים, צירוף מסמכים ומעקב סטטוס.

**טכנולוגיה:**
- Frontend: React 19 + Vite + Tailwind CSS
- Backend: Fastify + Prisma ORM + TypeScript
- DB: PostgreSQL 16
- אחסון קבצים: MinIO (S3-compatible) עם TTL
- Docker Compose לסביבת פיתוח

## 2. תהליכים עסקיים

### תהליך א: רישום לקורס מתקדם

```
┌──────────┐     ┌───────────┐     ┌───────────┐     ┌──────────────┐     ┌────────┐
│ משתתף    │ ──→ │ ראש צוות  │ ──→ │ קה"ד ענפי │ ──→ │ מפקד בי"ס   │ ──→ │ אושר!  │
│ מגיש     │     │ מאשר      │     │ מאשר      │     │ אישור סופי   │     │        │
│ בקשה     │     │ (שלב 1)   │     │ (שלב 2)   │     │ (שלב 3)      │     │        │
└──────────┘     └───────────┘     └───────────┘     └──────────────┘     └────────┘
      │                │                  │                   │
      │          אם דוחה           אם דוחה            אם דוחה
      └────────── נדחה ←─────────── נדחה ←──────────── נדחה
```

**פירוט:**
- משתתף נכנס לקטלוג קורסים ← בוחר מחזור ← לוחץ "הירשם" ← מודאל נפתח עם אפשרות צירוף קבצים
- הבקשה נוצרת בסטטוס `PENDING_TL`
- ראש צוות רואה badge עם מספר הבקשות הממתינות ← אשר/דחה
- אם אושר → עוברת לקה"ד ענפי (`PENDING_COORD`)
- קה"ד ענפי אשר → עוברת למפקד בי"ס (`PENDING_BIS`)
- מפקד בי"ס אשר → `APPROVED`
- בכל שלב ניתן לדחות עם סיבה

**סטטוסים:**
| סטטוס | משמעות | מי רואה |
|--------|--------|---------|
| PENDING_TL | ממתין לראש צוות | ראש צוות |
| PENDING_COORD | ממתין לקה"ד | קה"ד ענפי |
| PENDING_BIS | ממתין למפקד | מפקד בי"ס |
| APPROVED | אושר | כולם |
| REJECTED | נדחה | כולם |

### תהליך ב: מועמדות לתפקיד הובלה (פיקוד)

```
┌───────────┐     ┌──────────────┐     ┌────────┐
│ ראש צוות  │ ──→ │ מפקד בי"ס   │ ──→ │ אושר!  │
│ מגיש עבור │     │ מאשר/דוחה   │     │        │
│ משתתף     │     │              │     │        │
└───────────┘     └──────────────┘     └────────┘
```

**פירוט:**
- ראש צוות פותח קורס מסוג "יסוד" או "הובלה" ← לוחץ "הגש מועמדות" (כפתור כתום)
- מודאל נפתח: בחירת משתתף, מוטיבציה, הערות, קבצים מצורפים
- מפקד בי"ס רואה badge ← אשר/דחה במודאל
- המשתתף רואה ב"האזור שלי" את סטטוס המועמדות

## 3. מבכים (מסכים)

### מסך 1: כניסה למערכת
**נגישות:** כולם
**תיאור:** רקע כהה-מקצועי, בחירת משתמש מרשימה מקובצת לפי תפקיד. אייקון Shield + לוגו Bisli. בסביבת פיתוח - בחירה ישירה.

---

### מסך 2: האזור שלי (דף הבית למשתתף)
**נגישות:** משתתף בלבד
**תיאור:** 
- **טיימליין אנכי** - קורסים מאושרים מסודרים לפי תאריך התחלה
  - כל קורס = כרטיס עם פס צבעוני בצד
  - מציג: שם קורס, מחזור, תאריכים, מיקום
  - תגיות: "עכשיו" (ירוק), "בעוד X ימים" (כחול), "הסתיים" (אפור)
  - קו אנכי עם נקודות כטיימליין
- **בקשות רישום** - רשימת כל הרישומים עם badge סטטוס
- **מועמדויות** - רשימת מועמדויות שהוגשו עבור המשתתף עם שם המגיש

---

### מסך 3: קורסים ולו"ז
**נגישות:** כולם
**תיאור:**
- כרטיסי קורסים מקובצים לפי חודש (אפריל 2026, מאי 2026...)
- כל כרטיס מציג: תאריך התחלה, שם קורס, מחזור, סוג (יסוד/מתקדם/הובלה), תאריכי לימוד
- לחיצה על כרטיס → **מודאל גדול (lg)** עם:
  - שם קורס + מחזור
  - תיאור מלא
  - שעות, מיקום, דרישות מקדימות
  - גאנט שלבים (אם הוגדרו)
  - כפתור "הירשם למחזור" (למשתתפים - מודאל עם קבצים)
  - כפתור "הגש מועמדות לפיקוד" (לראש צוות - כתום)
  - רשימת משתתפים (למנהל)
- ארכיון: מחזורים שהסתיימו מופיעים בתחתית באזור מקווקו

---

### מסך 4: מועמדות לפיקוד
**נגישות:** ראש צוות, מפקד בי"ס
**תיאור:**
- **ראש צוות** - רואה מועמדויות שהגיש + כפתור "הגש מועמדות" (מודאל)
- **מפקד בי"ס** - רואה את כל המועמדויות + אשר/דחה במודאל
- כל מועמדות = כרטיס עם: שם מועמד, קורס, מוטיבציה, הערות, קבצים מצורפים, סטטוס צבעוני
- טופס הגשה (מודאל lg): בחירת משתתף, מוטיבציה, הערות, drop zone לקבצים

---

### מסך 5: אישור רישום
**נגישות:** ראש צוות, קה"ד ענפי, מפקד בי"ס
**תיאור:**
- כל תפקיד רואה רק את הבקשות שממתינות **שלו**
- כותרת דינמית לפי תפקיד ("הצוות שלך" / "הענף" / "אישור סופי")
- כרטיסים: שם משתתף, קורס, מחזור, ענף, צוות, קבצים מצורפים
- כפתורי "אשר" (ירוק) + "דחה" (אדום)
- לחיצה → מודאל קטן (sm) עם שדה הערות
- Badge counter בסיידבר מראה כמה ממתינים

---

### מסך 6: ניהול מערכת
**נגישות:** מפקד בי"ס בלבד
**תיאור:**
4 טאבים:
1. **משתמשים** - טבלה + חיפוש + סינון לפי תפקיד/ענף + יצירה/עריכה במודאל
2. **קורסים ומחזורים** - רשימת קורסים + מחזורים + יצירה/עריכה
3. **ענפים וצוותות** - מבנה ארגוני + הוספה
4. **יומן פעולות** - audit log של כל הפעולות במערכת

## 7. הרצה מקומית

```bash
git clone git@github.com:airbnbmate/coursit.git
cd cursit
docker compose up -d          # PostgreSQL + MinIO
npm install
cd backend
npx prisma db push
npx tsx src/scripts/seed/dev.ts
cd ..
npm run dev
```

**כתובות:**
| שירות | כתובת |
|--------|--------|
| Frontend | http://localhost:3005 |
| Backend API | http://localhost:8000 |
| MinIO Console | http://localhost:9001 |
| DB Viewer | http://localhost:8081 |
